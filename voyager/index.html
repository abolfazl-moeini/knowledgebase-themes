Documentation, executable.

Voyager is a split-pane documentation reader. The doc on the left. A live playground on the right. The two stay in sync as you read — scroll the article and the corresponding code loads in the playground. Click ↗ Run on any snippet to execute it without leaving the page.

How it works

Read & run

Every code example in the doc is a runnable snippet. Click ↗ Run to load it into the playground and execute it.

In sync

As you scroll the article, the matching snippet in the playground stays active. The two panels breathe together.

No more guesswork

No more "the code in this article is illustrative." What you read is what you run.
