Getting started

Set up Drift

At the heart of Drift is an open-source version control system (VCS) called Drift Core. Drift Core is responsible for everything Drift-related that happens locally on your computer.

Connecting to Drift with SSH

You can connect to Drift using the Secure Shell Protocol (SSH), which provides a secure channel over an unsecured network.

Creating and managing repositories

You can create a repository on Drift to store and collaborate on your project's files, then manage the repository's name and location.
